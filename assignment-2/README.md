# Assignment 2 - Transaction Detective

This folder contains the materials for the transaction detective exercise: examining real Solana transactions and identifying accounts, instructions, and programs.

## Contents

- `Solana_Transaction_Detective_Report-1.md` - report with the transaction analysis
- `task.md` - short description of the original assignment goal

## What this assignment demonstrates

- reading transaction metadata
- identifying accounts involved in a transaction
- mapping instructions to programs
- understanding execution flow on Solana

## Notes

The report is the main deliverable for this assignment. The goal is to show that a transaction can be decomposed into its accounts, instructions, and on-chain program calls.
