# Assignment 6 Task

Create a decentralized on-chain profile using a Program Derived Address and a client that can create, update, and read that profile.

## Expected outcome

- a deterministic PDA-based profile account
- initialize and update instructions
- a client that derives the PDA and reads the stored data
- tests that verify address derivation and state persistence

## Focus

This assignment builds on Anchor by adding PDA-based architecture and a more realistic on-chain data model.
