# Assignment 1 Task

Create a wallet, receive test SOL, send the first transaction on Solana, and analyze that transaction in Solana Explorer.

## Expected outcome

- a working Solana wallet
- a funded testnet or devnet account
- one successfully submitted transaction
- a saved transaction link or reference

## Focus

The assignment is about first contact with the Solana ecosystem and understanding how a transaction appears in the explorer after it is confirmed.
