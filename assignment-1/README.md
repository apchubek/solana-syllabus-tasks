# Assignment 1 - First Transaction on Solana

This folder contains the materials for the first course task: creating a wallet, getting test SOL, sending a transaction, and reviewing it in Solana Explorer.

## Contents

- `solana_transaction_link.txt` - transaction link or reference collected during the assignment
- `task.md` - short description of the original assignment goal

## What this assignment demonstrates

- basic Solana wallet setup
- testnet or devnet SOL acquisition
- sending the first transaction
- checking transaction details in Explorer

## Notes

The implementation is intentionally minimal because the main goal is to document the first successful interaction with Solana and preserve the transaction reference.
