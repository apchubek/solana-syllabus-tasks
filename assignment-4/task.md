# Assignment 4 Task

Create and deploy the first standalone Solana program in Rust, then call it from a client.

## Expected outcome

- a Solana program written without Anchor
- a deployed Devnet program ID
- a client that submits at least one instruction
- a transaction visible in Solana Explorer

## Focus

This assignment covers the full manual flow of Solana program development: instruction design, account handling, deployment, and client interaction.
